# Agent Routing

These files are lightweight task entrypoints for agents. They should stay
short and point to the authoritative human-readable docs.

| File | Use when |
| --- | --- |
| [`develop-resolver.md`](develop-resolver.md) | Adding or modifying resolver source |
| [`test-resolver.md`](test-resolver.md) | Adding tests, CI jobs, fixtures, or smokes |
| [`verify-empirically.md`](verify-empirically.md) | Reproducing real SDK-backed reviewer checks |
| [`use-cli.md`](use-cli.md) | Working on or using the diagnostic CLI |
| [`integrate-openusd.md`](integrate-openusd.md) | Embedding the resolver in an OpenUSD client |
| [`integrate-ovstage.md`](integrate-ovstage.md) | Integrating the resolver into an ovstage host |
| [`release.md`](release.md) | Verifying a source build or local install |
| [`triage.md`](triage.md) | Investigating resolver, ovstorage, or OpenUSD failures |
