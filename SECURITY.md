# Security Policy

NVIDIA is dedicated to the security and trust of our software products and
services, including all source code repositories managed through our
organization.

If you need to report a security issue, please use the appropriate contact
points outlined below. **Do not report security vulnerabilities through GitHub
issues, pull requests, or discussions.** If a potential security issue is
inadvertently reported via a public channel, NVIDIA maintainers will limit
public discussion and redirect the reporter to the private disclosure channels.

## Reporting a Potential Security Vulnerability

To report a potential security vulnerability in ovstorage or any other NVIDIA
product, use one of the following channels:

- **Web:** [NVIDIA Security Vulnerability Submission Form](https://www.nvidia.com/object/submit-security-vulnerability.html)
- **Email:** psirt@nvidia.com
  - Use the [NVIDIA public PGP key](https://www.nvidia.com/en-us/security/pgp-key)
    for encrypted communication.
  - Include: product name and version/branch, vulnerability type, reproduction
    steps, proof-of-concept or exploit, and potential impact.

NVIDIA offers public acknowledgement when an externally reported issue is
addressed under the coordinated vulnerability disclosure policy. The
[NVIDIA PSIRT policies page](https://www.nvidia.com/en-us/security/psirt-policies/)
is the authoritative source for current disclosure handling, bug-bounty
program status, and acknowledgement criteria.

## NVIDIA Product Security

For all security-related concerns, see NVIDIA's [Product Security portal](https://www.nvidia.com/en-us/security).
