# Third-Party Notices

This repository ships an OpenUSD `ArResolver` plugin, a standalone
diagnostic CLI, and a supporting C++ library. All source code in this
repository is NVIDIA-authored and licensed under the terms recorded in
[`LICENSE`](LICENSE); see [`NOTICE`](NOTICE) for the NVIDIA notice.

No third-party source code is vendored into this repository. The
resolver depends on OpenUSD and ovstorage as external libraries: both
are located through CMake at configure time and linked against by the
build. Consult each project's own distribution for the licenses that
apply to those linkage targets.

Deterministic USD and USDZ fixtures generated by the tests are authored in
this repository. Opt-in live tests fetch public AWS S3 and Hugging Face assets
at test time; those assets are not redistributed in the source archive and
remain subject to the licenses published by their providers.

Third-party attribution entries must be added here before introducing
any vendored source, generated source, or distributed artifact that
includes third-party code.

## Binary package C API dependency

The wheel statically links the ovstorage 0.3 C API (Apache-2.0). The native
CMake package includes that static C API library and the ovstorage public
headers, preserving their upstream notices. The C API includes the MIT-licensed
tomlc17 parser, Copyright 2024-2026 CK Tan. Its license is installed at:

- Wheel: `ovstorage_usd_resolver/licenses/tomlc17-LICENSE`.
- Native CMake package: `licenses/tomlc17-LICENSE`, relative to the install prefix.

This notice, `LICENSE`, and `NOTICE` are installed in the wheel's
`.dist-info/licenses/` directory and the native prefix's `licenses/` directory.
Rust provider libraries and their notices are supplied by the separate
ovstorage distribution. OpenUSD is supplied by the consuming host and is not
included in either binary package.
