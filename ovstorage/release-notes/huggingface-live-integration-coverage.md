**The integration suite exercises the read-only Hugging Face Hub backend against the live Hub.** Naming a public fixture repository (`OVSTORAGE_HUGGINGFACE_REPO_ID`, anonymously or with an optional token) opts all three legs — Rust, C++, and Python — into a read-only scenario family that lists, stats, reads, range-reads, and version-pins objects the fixture itself provides, asserting only self-consistency. Write-capable backends skip the read family visibly, and the write-family scenarios skip visibly on a read-only backend instead of failing.
