# Security Policy

If you believe you have found a security vulnerability in
`ovstorage-usd-resolver`, please report it privately.

Send a detailed report to **psirt@nvidia.com** ([PSIRT — NVIDIA Product
Security Incident Response Team](https://www.nvidia.com/en-us/security/)).
Include:

- a description of the vulnerability and its potential impact;
- steps to reproduce, including affected version or commit;
- any relevant logs, stack traces, or proof-of-concept material;
- the earliest version you observed the issue in and, if known, the
  earliest version that fixes it.

Please do not open public GitHub issues or pull requests for
suspected security vulnerabilities. NVIDIA PSIRT will acknowledge
your report and coordinate disclosure and remediation timelines
directly with you.
